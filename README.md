# KARIN AI

KARIN AI is a paired Windows + Android personal desktop assistant concept with an ice-blue command-center interface.

## Targets
- Windows 10/11 desktop launcher
- Android companion
- Wake word: **Karin**
- Animated AI core
- Routine reminders
- Local document/app launcher
- PC ↔ Android pairing and local file bridge
- Optional OpenAI API integration via `OPENAI_API_KEY`

Build artifacts are produced by GitHub Actions.
